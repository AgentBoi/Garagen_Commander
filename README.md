# Random Commander

A small React + Vite web app that uses the Scryfall API to draft random Commander cards for each player and keep a local history of rounds.

## Features
- Start a new game or view previous rounds
- Add players, drag to reorder, or randomize the order
- Reveal three hidden Commander cards per player and confirm a selection
- Show the final lineup and persist all rounds in local storage

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
